05CalendarEdited

Read-only links that let ATLAS see your events. Where to find yours:

  • Google — calendar.google.com → Settings → pick the calendar → Integrate calendar → Secret address in iCal format.
  • iCloud — share the calendar, tick Public Calendar and copy the webcal:// link.
  • Outlook — Outlook on the web → Settings → Calendar → Shared calendars → Publish a calendar → copy the ICS link.

Several calendars: separate with commas, and name them if you like: Work=https://…. Treat these links like passwords.

New events open pre-filled in that calendar and you click Save there. “Your day” is used when looking for free time.

06Texting & callsEdited

On a Mac, texts can go through the Messages app (iMessage) with no setup — Twilio is optional there. Calls open your computer’s calling app and you press Call.

All three Twilio values are on the Twilio Console home page. Trial accounts can only text numbers you have verified. The country code applies to numbers written without a leading +.

07Smart homeEdited

In Home Assistant, open your profile (your name, bottom left) → Security → Long-lived access tokens → Create token. A password written into the URL shows as •••• and is kept when you save.

Extra domains, services or devices that need your approval (* = everything). Locks, alarms, garage doors, valves and cameras always ask first.

08Web browserEdited

ATLAS opens its own Chrome or Edge window to book tables and run web errands. Sign in to OpenTable, Resy and Google there once — it stays signed in, separate from your everyday browser. Final Book / Pay / Submit clicks always wait for your approval.

Only for computers without a screen: you can’t sign in, solve a CAPTCHA or watch a booking in a window you can’t see.

Automatic tries Chrome, then Edge, then Playwright’s Chromium. The vision model reads screenshots of date pickers and seating maps. Changes apply the next time the window opens.

09Data sourcesEdited

Stocks, crypto, economic data and sports scores all work with every field here blank. These only tune the sources or raise their rate limits.

Ticker symbols as Yahoo Finance writes them, separated by commas.

SEC EDGAR asks for a contact email in the User-Agent of every request. Without one, filing and financials lookups may be refused. It is sent only to SEC.

Optional. Without a key, economic data comes from FRED’s public CSV downloads, with the same figures. Free keys: fred.stlouisfed.org.

Optional free “demo” key from coingecko.com/en/api for higher crypto limits (about 30 calls a minute). Works without one.

Region: two letters (US, GB, CA, IN…) for trending tickers and stock news. Top movers are always US. Time zone: an IANA name such as America/Chicago, for game times.

The leagues the scores panel follows, separated by commas, e.g. nfl,nba,epl,f1,ucl.
